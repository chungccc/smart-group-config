Smart Group 配置

基于 Smart 核心的代理配置，所有策略组均为 Smart 自动选择节点，含一个手动选择节点组

特点
按地区划分的 Smart 策略（HK / JP / SG / US 等）
全部策略组均为 Smart 自动决策
PRM / BSC 线路分层

规则模式，支持常见应用分流

环境
R68S
OpenWrt
OpenClash

使用说明

本配置基于个人使用习惯编写

建议至少使用 3 个及以上机场

需根据自身节点命名进行适当调整

未特别处理 DNS 泄露问题（偏性能取向）

策略组结构（简要）

应用分流：YouTube / Netflix / Telegram / ChatGPT / GitHub 等
地区策略：HKG / JPN / SGP / USA / TWN

注意
节点数量和质量会直接影响效果
