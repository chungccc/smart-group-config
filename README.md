适用于 **OpenClash** 和 **Stash** 的智能代理配置。

通过 **节点自动分类、地区筛选、智能测速和规则分流**，减少手动选择和维护节点的工作。

## 📦 配置版本

### 🛜 OpenClash

适用于 OpenWrt / ImmortalWrt 路由器。

**主要特点：**

* Smart 智能节点优选
* 多机场统一管理
* HK / JP / SG / US 等地区自动分类
* 支持 `PRM / BSC` 节点等级
* Override 节点名称标准化
* 自动测速与故障切换
* Rule Providers + GEOSITE 规则分流

### 📱 Stash

适用于 iPhone / iPad / Mac。

**主要特点：**

* 多机场统一管理
* HK / JP / SG / US 地区自动分类
* URL-Test 自动测速
* 自动过滤机场无效节点
* OpenAI / TikTok / Emby 等独立策略
* GEOSITE 规则分流
* 广告拦截

## 🔄 两个版本

|           | OpenClash             | Stash       |
| --------- | --------------------- | ----------- |
| 平台        | OpenWrt / ImmortalWrt | iOS / macOS |

| 多机场       | ✅                     | ✅           |
| 地区分类      | ✅                     | ✅           |
| PRM / BSC | ✅                     | ❌           |
| Override  | ✅                     | ❌           |

## 🎯 项目理念

> **让节点自动分类，让测速自动选择，让规则自动分流。**

无需频繁手动选择节点，新增机场后按照对应的命名规则配置即可。
